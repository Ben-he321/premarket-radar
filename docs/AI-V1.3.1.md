## 执行与恢复

在 `premarket-radar-ai-m1` 项目目录使用 `.venv/Scripts/python.exe`：

- `-m src.v131.evidence`：冻结旧最大盈亏样本，审查三项行动和去重缺价。只定向 SIP 查询。
- `-m src.v131 restate`：确认旧 486 意图哈希后从冻结意图重述；已有有效账户按哈希恢复，不重复计算。
- `-m src.v131 probe`：复用既有真实行情缓存，定向增量补齐；检查全部 66 候选，不生成意图。
- `-m src.v131 paper-service`：工程门槛通过后，一个 Windows 进程管理两个独立账本。
- `-m src.v131 report`：从已有输出创建白名单验收包，不重跑研究。

新服务的 Windows 登录任务名为 `BenAITrading-EvidenceForward-V1_3_1`。
持续状态查看 `forward_status.json`；`forward/activation.json` 固定真实启动时刻和代码哈希。
`forward/service.lock` 防止重复进程。创建 `forward/STOP` 空文件停止新服务；恢复时只删除该
STOP 文件，再启动同名任务。不得删除数据库、意图或状态文件。旧 V1/V1.1 服务不受影响。
登录任务依赖本机开机、用户登录和网络，不是云端服务，也不保证休眠期间继续运行。

原页面 `http://localhost:8513/` 新增「证据修复与前向对照」标签。页面只读，刷新不触发研究或下单。

## 执行与风险口径

- 原 0.5% 风险、20% 单股上限、4 持仓、5% 止损、H20、整数新买入、费用与摩擦保持。
- 可用现金＝已结算现金－持仓退出费用－未成交买入/退出预算－负净回收待结算负债。
  预留不是资产或手续费；卖出后若净额为负，持续预留到原 T+1 结算，防止提前释放被重复支用。
- 股息应收不计可用现金。拆并股调整股数/价格单位，不按股数倍增固定退出费。
- 公司行动与行情请求共用日期分段身份。CUSIP 不符可能是未审查换股，只有有证据的另一证券
  才标记不适用；未知行动只阻断对应证券。
- 前向两个账本共用缓存、NYSE 日历、已知信号日的哈希优先顺序、504/20/126 资格窗口。
  历史窗口固定 126 条最低共同有效训练数据；不引入新的动量参数搜索。
- 决策窗口纽约时间 06:30～09:25；信号使用已定稿日线；买入和条件退出意图同时冻结。
  基于 Alpaca Basic 至少 20 分钟延迟的真实 SIP 历史分钟数据，均为虚拟成交代理。
  不需要最新 SIP 权限，不回退到 IEX、Futu、yfinance 或合成数据。
- 休眠/断网恢复只处理已经存在的意图，不补造已错过的决策。单证券 API 错误不会让另一证券
  假性过期；实际无报价才按冻结规则处理。未知退出报价持仓留存并标记。
- 观察 60 个交易日后停止新入场，继续原持仓退出/结算。累计不足、缺报价或一笔盈利都不能
  证明统计优势。自然完整生命周期在实际发生前一直标记待验证。
