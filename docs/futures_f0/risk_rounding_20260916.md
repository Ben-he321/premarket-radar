# 基础首仓预算：计入已知的不利退出 tick 取整

本修复不重跑历史、不改写原12个空仓工程账户或旧适配结果。
原2ATR保护、初始115美元风险预算、保证金、压力成本情景和giveback规则保持原值。

旧计算把保护价到基础止损代理之间的距离近似为2tick，遗漏了保护价本身不在报价网格上的不利取整。
现在 `engine._size` 与 `fitness` 共用 `risk.baseline_initial_risk`：

```
F = 场景实际入场代理（已含该场景入场滑点）
X_base = 将保护价按退出方向不利取整，再加基础退出2tick
L_base = direction * (F - X_base) * multiplier + 2 * 基础每边佣金
首仓风险手数 = floor((账户权益 * 原风险比例) / L_base)
```

不另加第二次入场滑点。压力情景仍用该情景的入场代理，但首仓退出预算仍为基础2tick与基础双边佣金。
压力实际止损代理另算；115美元仅为首仓预算，不是未来跳空或实际执行损失的保证上限。
共享报价取整保留原引擎的1e-10 tick浮点边界容差，Decimal用于预算除法，避免恰好115美元因浮点噪声被误拒。

人工MZC反例（不是行情、意图或订单）：乘数5，tick0.5，开盘/前收盘454，ATR10.05，每边2tick，每边佣金2美元，前20期人工量各1000。

|方向|保护价|入场代理|基础退出代理|旧预算|新预算|新首仓手数|
|---|---:|---:|---:|---:|---:|---:|
|多|433.9|455|432.5|114.50|116.50|0|
|空|474.1|453|475.5|114.50|116.50|0|

独立金额断言另覆盖：乘数6/tick0.5/ATR8.25时115美元允许1手；ATR8.250001跨下一tick时118美元拒绝。
包括不同tick价值、多空方向、原浮点报价取整、压力场景与基础佣金的分离。
测试同时确认没有创建历史账户交易或修改本金。

`zero_gap_atr_ceiling_illustration` 保留为未取整连续必要上界，并明确标注不能作为准入阈值。
人工MZC例中旧连续上界10.1不能保证准入；原报价网格下ATR10.0的预算114美元可满足，10.05的116.5美元不能满足。

本机最终全F0离线结果：396项与12个子测试通过。测试使用人工数据，不构成非零历史交易验证或策略评价。
