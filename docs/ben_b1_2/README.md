## 解释边界

历史 SIP L1 的显示数量和摩擦模型不能证明真实排队或实盘成交。供应商最终历史收盘数据假设在收盘后一分钟可得，只用于离线事件时钟；当前 Basic 是否能够在该决策时点实时提供同样输入仍未验证，因此不启动 Ben 前向账户。

RTH 价格由实际常规时段分钟及供应商收盘字段构造。供应商日线全部字段并不自动等于纯常规交易时段，因此不能直接用其全时段高低价和成交量替代。本轮没有逐点独立核验所有收盘竞价量，缺失的排序量不填零。NOW 的预热期拆股由生效日事件调整历史股数单位；未来公司行动不能提前修改过去指标。

一季度价格可用并不等于全池财报和执行资料完整。所有共同账户均保留 `COVERAGE_LIMITED`，因为缺失候选会影响资金竞争和排名，当前业务范围也不是完整的历史范围版本。A/B 结果不混合，不因 Q1 多出交易而宣布更优。SPY/QQQ 仅为相同本金、相同日期的辅助基准；不加入策略名单，不将覆盖受限结果宣称为独立盈利证明。

报告估值与执行估值分开：执行继续采用原内核当时可得价格；另用账本副本按当日供应商收盘价生成可比的期末估值，不改动账户。期末不假设已出售持仓，不扣尚未发生的末次卖出费用，分红应收、未结算现金与现金分别列出。
