# B1.2 共同资金预留边界

共同资金账户使用 `src.ben_b1_2.shared.SharedReplayEngine`，Q0 与 Q1 使用相同现金规则。仅限冻结的 `P50_PRIMARY`，本金 5500 美元、最多两笔持仓，不借款，不因已有订单部分成交而释放其未成交部分的资金承诺。原内核、原结果和独立 20 样本不被改写。

工程测试发现的具体边界是：第一个订单买入 10/27 股后，新的盘口价格上涨；若把其剩余 17 股承诺从新候选的资金计算中遗漏，第二个候选会重复占用资金。固定测试中，剩余承诺与退出预留合计 3574.35 美元，而现金只有 3475.98 美元，差额 98.37 美元。这是明确标记的工程输入，不能称作已发现真实历史账户出现该资金缺口。

每个未完成买单的预留为：剩余整数股数乘以既定限价的逐股美分上界，加上尚未支付的入场佣金和仍未预留的未来退出腿佣金。新候选可用现金为实际现金减去已有持仓退出预留、再减去所有未完成买单的上述承诺。限价的美分上界只用于保守预留，实际成交仍执行原价格、摩擦和费用公式，不能把预留上界记成新增手续费。

新建订单时，数量只能为满足冻结规则和实际现金容量而减少；不扩大头寸，不搜索信号参数。订单一旦建立，数量与限价保持不变。后续部分成交继续保护其他未完成买单的资金；不足时明确等待，不能允许负现金或额外注资。

决策证据保留当时净值、当前估值状态、现金、已有退出预留、盘口剩余显示数量、冻结摩擦和所有未完成入场承诺。未知当日估值不会被当作已经核实的净值。日度权益另列 `shared_reserved_entry_costs` 与 `shared_available_uncommitted_cash`。

该类有独立 checkpoint 版本，普通 Compact 类不得恢复后静默丢失共同资金规则。独立测试已核对上述 98.37 美元边界、后续两笔余单成交、跨恢复预留、固定数量与限价，以及无资金冲突时 Q0/Q1 与原 Compact 金融状态逐项一致。测试记录保存在 `engineering/shared_cash_boundary_final.log` 和本轮最终工程报告中；这些工程通过不等同于真实共同账户收益证明。
